# The New York Food Guide

A curated, two-page guide to New York City's most exciting dining experiences.
Select a borough to browse critic-tested restaurants with signature dishes and
reviews, and meet the culinary leaders celebrated in the Food Guide Honors.

## Getting started

This project is a static site—open `index.html` in your browser to explore the
borough recommendations or jump to `recognitions.html` for the honors list.

For local development with live reloading, any static server will work. Example
using Python 3:

```bash
python -m http.server 8000
```

Then navigate to <http://localhost:8000>.

## Structure

- `index.html` – Landing page with borough selector, featured stories, and quick
  links to the honors list.
- `recognitions.html` – Food Guide Honors page highlighting tastemakers and
  community leaders.
- `assets/css/styles.css` – Shared styles for typography, layout, and cards.
- `assets/js/boroughs.js` – Interactive borough switcher and restaurant data.
